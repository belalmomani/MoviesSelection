# Movies Selection

تطبيق Android أصلي (Kotlin + Jetpack Compose) لاكتشاف الأفلام والمسلسلات بأسئلة تضيّق النتائج خطوة بخطوة. البيانات من TMDB، ومعها Wikidata للأعمال العربية.
الحزمة: `com.tvseries.Movies` (صالحة؛ الأحرف الكبيرة مسموحة. البديل `com.tvseries.movies` إن رُفضت يومًا).

> **الحالة:** كُتب المشروع بلا مترجِم في بيئة الكتابة، فالتحقق يتم عبر GitHub Actions على هاتفك. أخطاء الترجمة تُصلَح من سجل الفشل.

## 1) التشغيل والتحديث (من الهاتف)
1. ارفع كل الملفات إلى مستودع GitHub (يفضَّل **خاص**)، **بما فيها** `.github/workflows` و`app/signing/movies-test.keystore`.
2. Actions ← **Build APK** ← Run workflow (يعمل تلقائيًا عند كل رفع إلى main).
3. بعد النجاح: Artifact `MoviesSelection-apk` + **Release** جديد باسم `build-N`.
4. **التحديث دون حذف:** كل النسخ تُوقَّع بمفتاح اختبار ثابت، و`versionCode = 100 + رقم التشغيل` (يتصاعد وحده). في «الإعدادات»: «🔔 يتوفر تحديث جديد» + «تنزيل وتثبيت»، وتظهر نقطة على أيقونة الإعدادات. المستودع: `UPDATE_REPO` في `app/config.properties`. المستودع الخاص يحتاج رمز GitHub (Contents: Read-only) يُلصق في الإعدادات.
   ⚠️ النسخة المثبتة قبل المفتاح الثابت تُحذف مرة واحدة فقط.
5. الإعدادات (`app/config.properties`): `TMDB_API_KEY`، `START_IO_APP_ID`، `ADS_ENABLED`، `UPDATE_REPO`، `PRIVACY_URL`. السر `TMDB_API_KEY` في GitHub يتقدّم على الملف. المفتاح يُدمج في الـ APK: استعمل مستودعًا خاصًا.

لا Gradle Wrapper عمدًا (ملف ثنائي)؛ الـ workflow يثبّت Gradle 8.9. JDK 17، AGP 8.5.2، Kotlin 2.0.20، minSdk 26، compileSdk 34.

## 2) الصفحات
**الشريط السفلي:** الرئيسية، تصفية، بحث، قوائمي، الإعدادات.
**الشريط العلوي:** 🤷 اختر لي · 👍 ذوقي · 🎁 الصندوق الغامض · 🗺️ العوالم · «المزيد» (🎡 الروليت الذكي · 🚪 ثلاثة أبواب · 🎚️ اضبط تفضيلاتي).
**الرئيسية:** 🌀 بوابة الزمن، سهرة جماعية، اختر حسب مزاجي، التصفية، تصفياتي المحفوظة، اختصارات النوع/الدولة، 💎 كنوز مخفية، صفوف الأعمال، بانر إعلاني.
**التفاصيل:** القصة، التقييم، المدة/المواسم والحلقات، الممثلون، أين أشاهده، أعمال مشابهة، مفضلة، شاهد لاحقًا، شاهدته، مشاركة، مقارنة.

## 2.5) نوع المحتوى العام: الكل / أفلام / مسلسلات
في أعلى الشاشات الرئيسية (بجانب الاسم) ثلاث شرائح **الكل | أفلام | مسلسلات**، تُحفظ وتُطبَّق على: التصفية (الجلب والنتائج)، البحث (يستعمل بحث النوع نفسه فتزيد نتائج المسلسلات ولا تظهر الأفلام)، الرئيسية (الصفوف والكنوز)، اختر لي، ذوقي، الأبواب، الصندوق، الروليت، العوالم، السهرة الجماعية، وبوابة الزمن (المحطات تُعاد جلبها للنوع المختار).

## 3) المحرك والتصفية
- OR داخل المحور و AND بين المحاور، واستبعاد، تراجع، وسؤال واحد في كل مرة (ترتيب المحاور ديناميكي حسب القدرة على التقليل).
- المعلومة المجهولة **لا تُعدّ عدم مطابقة**: تظهر تحت «قد تطابق»، ويُكمَّل نقصها بجلب التفاصيل.
- «المزيد المطابق» يطلب من TMDB أعمالًا تطابق شروطك؛ الأعمال العربية: حد أصوات منخفض + طلب لكل دولة + Wikidata (وسم 🌐).
- **المرحلة الثانية (الفلترة النهائية):** عند بقاء 2–12 عملًا: الأبطال ← الأجواء (اختيار متعدد) ← القصة (واحدة أو اثنتان) ← مواجهة أخيرة. كل مرحلة قابلة للتخطي.
- «ما لا أريده»: لا رعب/خيانة/نهاية حزينة/دماء/مدرسة/أفلام طويلة. الأنواع والمدة رسمية؛ البقية **تُستنتج من الكلمات المفتاحية الإنجليزية** وقد تفوتها أعمال.

## 4) الميزات الخاصة
- **اختر لي:** 3 أسئلة شعورية تضبط المنزلقات ثم سؤالان يختارهما التطبيق ثم «ثلاثة أبواب».
- **ذوقي:** عمل واحد في كل مرة (نعم/لا + سبب)، ملف ذوق **محلي** (أنواع مفضلة/متجنَّبة).
- **الصندوق الغامض:** ثلاثة أعمال بلا أسماء؛ الأنواع وتنبيهات المحتوى تبقى ظاهرة.
- **العوالم:** خريطة عوالم/فروع محلية من الأنواع والكلمات (تقديرية).
- **الروليت الذكي:** قرعة بين الأعمال التي اجتازت **كل** الشروط الإلزامية فقط، الأنسب أحظّ، ~10% مفاجآت من المؤهَّلين.
- **ثلاثة أبواب:** الأقرب لذوقك / مفاجأة محسوبة / خيار آمن (تفاصيله كاملة).
- **اضبط تفضيلاتي:** هدوء↔توتر، واقعية↔خيال، خفيف↔عميق (تفضيلات المستخدم، لا حقائق) + شروط «لا أريد».
- **سهرة جماعية:** تقاطع تفضيلات شخصين. **المقارنة:** حتى 3 أعمال جنبًا إلى جنب. **كنوز مخفية:** تقييم 7+ وأصوات 1,500–20,000 بترتيب موزون.
- **🌀 بوابة الزمن (النسخة 2):**
  - **مقدمة سينمائية (7 ثوانٍ، قابلة للتخطي، مرة لكل جلسة):** تنفتح البوابة تدريجيًا وتظهر داخلها لمحات من عوالم متعاقبة، ثم تندفع عبر ممر زمني تتحول جدرانه إلى ملصقات أعمال حقيقية، ثم وميض ووصول إلى «عالم الأفلام».
  - **13 محطة بيئية** تتغير فيها البيئة نفسها (لا صفحة): بوابة المستقبل، روما القديمة، قلعة العصور الوسطى، غابة الديناصورات (مع ديناصور يمشي وبركان)، مصر القديمة، الفايكنج، الغرب الأمريكي، القراصنة، الحرب العالمية الثانية، الحرب الباردة، السايبربانك، ما بعد الكارثة، السينما الكلاسيكية. المشاهد مرسومة برمجيًا (أشكال ظلّية مبسطة).
  - **أعمال كل عالم من TMDB فعلًا:** تُحَلّ كلمات مثل `dinosaur` و`ancient rome` بخدمة البحث الرسمية عن الكلمات المفتاحية (لا معرّفات مخترعة) ثم تُجلب الأعمال المرتبطة بها؛ الغرب بنوع Western والكلاسيكية بسنوات 1930–1959. إن قلّت الأعمال يُقال ذلك صراحة («بيانات قليلة»)، وإن انعدمت لا يُعرض شيء مختلق وتُتخطى المحطة تلقائيًا.
  - **سينما حولك:** حلقة شاشات 360° بأحجام ومسافات مختلفة (يمين/يسار/أمام/خلف + صف أعلى وأسفل)، تتبدّل أعمالها تلقائيًا أثناء الرحلة، والشاشة الأمامية تشغّل مقطعًا ~5 ثوانٍ (YouTube الرسمي، صامت افتراضيًا) وبقية الشاشات متحركة. اضغط أي شاشة لفتح العمل.
  - **📡 الرادار الزمني:** حلقة مائلة ثلاثية الأبعاد تدور مع اتجاه نظرك، فيها المحطات كنقاط (حجم النقطة = عدد الأعمال؛ أخضر كافٍ، أصفر قليل، أحمر لا بيانات، رمادي لم يُفحص). اضغط نقطة للانتقال، و«افحص كل المحطات» يملؤه تدريجيًا.
  - **⚡ قفزة زمنية:** انتقال عشوائي إلى محطة (يفضّل الغنية بالأعمال) مع تغيير زاوية الرؤية.
  - **✨ شاشة تجذب الانتباه:** كل ~22 ثانية تُبرز شاشة ~4.5 ثانية (تكبر وتتوهج)؛ «اقترب من الشاشة المميزة» يدير الرؤية نحوها، وتجاهلها لا يفتح شيئًا.
  - **وضعان:** تلقائي (افتراضي) ويدوي (خريطة الزمن، السابق/التالي، إيقاف/استئناف، سحب 360°، سرعة ×0.5…×3، عودة للتلقائي) مع حفظ الموضع عند التبديل.
  - **🕳️ ثقب الزمن:** منطقة تنحني فيها البيئة حول ثقب أسود: شاشات **تدور في مدارات** (الأقرب أسرع)، وتتسارع المؤثرات وتتباطأ مع «تمدد الزمن» (يُعرض معامله)، وفقاعات صغيرة لعوالم مختلفة **منضغطة ومتداخلة** حول الثقب. تظهر فيه أعمال مختارة عشوائيًا من **حقب مختلفة** (من المحطات المحمّلة فعلًا فقط). تُفتح تلقائيًا نادرًا أثناء الرحلة (احتمال ~25% عند انتقال المحطة، وبينها ≥ دقيقتين) أو بزر «ثقب الزمن»، ويدوم ~16 ثانية في الوضع التلقائي ثم **يُلقي بك في محطة بعيدة** (انتقال نادر بين عصور متباعدة)؛ في الوضع اليدوي تبقى حتى تخرج.
  - **الشاشة التي تبتلعك:** الضغط على أي شاشة لا يفتح الصفحة فورًا: تكبر الشاشة ويتحول إطارها إلى بوابة (دوّامة)، ثم تعبر إلى مشهد **أصلي من رسم التطبيق** مستوحى من نوع العمل (رعب ← رماد وأطلال، خيال علمي ← مدينة مستقبلية، فانتازيا ← قلعة، ويسترن ← غرب...)، ثم تظهر معلوماته (القصة والأنواع والتقييم) مع «افتح صفحة العمل / شاهد لاحقًا / عودة». نحو 3 ثوانٍ وقابل للتخطي. **لا يُعاد بناء مشاهد من الأفلام** (حقوق)، وهذا مكتوب في الواجهة.
  - حدود: محاكاة 3D تقريبية (إسقاط على حلقة)، مقطع حي واحد فقط، كلمات TMDB إنجليزية ونتائجها تعتمد على تغطيتها، ولم تُجرَّب على جهاز.
- **تذكير أسبوعي** (معطّل افتراضيًا)، **مسح بياناتي المحلية**، لغة عربي/إنجليزي مع RTL، فاتح/داكن، شاشة أعطال تعرض نص الخطأ لنسخه.

## 5) حدود معروفة (للأمانة)
- التصفية على **ما حُمّل** من TMDB لا على قاعدته كلها. قاموس التصنيفات الواسع (أنواع فرعية دقيقة، قصة الانتقام...) غير متوفر كبيانات.
- المزاج والتوتر والعوالم والمنزلقات **تقديرات** من الأنواع (موسومة DERIVED/UNVERIFIED في `core`).
- تغطية TMDB للأعمال العربية أضعف (أوصاف، صور، تقييمات). Wikidata جزئي.
- المقاطع تحتاج إنترنت، وبعض الأعمال تمنع التضمين (تظهر رسالة وتبقى حركة الملصق). مقطع حي واحد فقط (الأمامي). المجسّم محاكاة أسطوانية وليست محرك 3D.
- التخزين SharedPreferences+JSON على الجهاز (لا حساب ولا سحابة). سجل البحث معطّل افتراضيًا.
- الأيقونة بسيطة؛ **شعار TMDB الرسمي غير مضمّن** (ملف يؤخذ من TMDB) — نص الإسناد في «حول».

## 6) الإعلانات (Start.io)
بانر في الرئيسية والتفاصيل فقط، **لا** في التصفية أو الاختيار ولا إعلانات بينية. `ADS_ENABLED=false` يزيل المكتبة كليًا (مجلد `src/noads`). نسخة debug تعرض إعلانات **تجريبية**. المكتبة `com.startapp:inapp-sdk:4.+` لم يُتحقق منها خارج البناء.

## 7) النشر على Google Play
1. مفتاح التوقيع: Actions ← **Create release keystore** (مرة واحدة) ← انسخ الملف وكلمة السر **احتياطيًا** ثم احذف الـ Artifact. أسرار المستودع: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
2. Build APK مع `build_release=true` ينتج `MoviesSelection-aab` (يوقَّع بمفتاح الأسرار؛ بدونها بمفتاح الاختبار).
3. سياسة الخصوصية: `docs/privacy.html` (املأ التاريخ والبريد، فعّل GitHub Pages على `/docs`، ثم ضع الرابط في `PRIVACY_URL`).
4. Data Safety: لا حساب ولا خادم خاص؛ مكتبة الإعلانات قد تجمع معرّف الإعلانات ومعلومات الجهاز (طابقها مع وثائق Start.io).
5. قبل النشر العام: شعار TMDB، مراجعة شروط TMDB التجارية، تجربة نسخة release (R8 غير مختبر)، واستبدال مفتاح الاختبار العلني بمفتاح الأسرار.

## 8) الاختبارات
`app/src/test`: محرك التصفية والتراجع والبيانات الناقصة، التقاطع، الأبواب والروليت، الذوق، الكنوز، الجدول الزمني للبوابة، الأعمال العربية، التفضيلات، التحديث، المراحل النهائية، عميل TMDB وWikidata عبر خادم وهمي. تُشغَّل في Actions (`:app:testDebugUnitTest`) قبل البناء.

## 9) TMDB والترخيص
This product uses the TMDB API but is not endorsed or certified by TMDB. الاستخدام التجاري يتطلب مراجعة شروط TMDB وترخيصها.
